Save slots

Each seed gets its own three save slots (their borders turn green), so switching seeds never loads another seed's save, and patching the same seed again keeps its saves. Each slot you use takes about 300 KB of Dread's save data, which is only freed by deleting Dread's save data in System Settings. Saves made before, in the shared slots, stay there.
