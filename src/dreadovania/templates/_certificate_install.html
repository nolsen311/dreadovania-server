How to install it
iPhone and iPad
Download it in Safari and allow the download. Open Settings, tap Profile Downloaded (or General → VPN & Device Management), install it and enter the password.
Android
Open Settings → Security → More security settings → Encryption & credentials → Install a certificate → VPN & app user certificate (names vary by phone), choose the file and enter the password.
Windows
Open the file, choose Current User, enter the password and keep the suggested store. Edge and Chrome use it.
macOS
Open the file, add it to the login keychain and enter the password. Safari and Chrome use it.
Firefox
Settings → Privacy & Security → Certificates → View Certificates → Your Certificates → Import.

Then close the browser completely and open this server again: it asks which certificate to use.
