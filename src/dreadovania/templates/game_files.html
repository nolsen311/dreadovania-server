What's needed

Patching a seed needs the extracted RomFS of your own copy of the game, version {{ supported | join(" or ") }}. Dump it from your game with a homebrew dumping tool on your Switch.

Game packages (.nsp, .xci) and console keys are never accepted. The game files stay on this server: they are never shown, downloaded or logged.

How to add them

Copy the RomFS folder to the server, then mount it at /data/romfs. system/ and packs/ should be directly inside it. For example, in compose.yaml:

volumes:
  - ./data:/data
  - /path/to/dread-romfs:/data/romfs:ro

The folder must be readable by the container's user (UID 10001). Uploading from this page will come in a later update.
